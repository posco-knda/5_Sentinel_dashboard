# Sentinel Dashboard (시연용 대시보드)

**5조 · 팀명 "감시자들"** — 냉간압연 설비 이상탐지 & 잔존수명(RUL) 예측 프로젝트의 시연용 웹 대시보드입니다.

> ⚠️ 이 저장소는 **공식 제출물이 아닙니다.** 강사님 진행가이드 기준 공식 제출물은 분석 저장소(`5조_감시자들_Sentinel`)에 있습니다. 이 대시보드는 결과보고서/발표 7장("현장 활용 근거")의 **시연 도구**로만 사용합니다.

분석 저장소: [`5조_감시자들_Sentinel`](../5조_감시자들_Sentinel) (조직 내 별도 저장소)

## 이게 뭔가요

기존에 만들어둔 예지보전(PdM) 대시보드 프로토타입을 그대로 가져온 것입니다. 화면 구성(이상탐지 현황 → 설비 상세 → 잔존수명/생존곡선 → AS-IS/TO-BE 비용 비교)이 이번 주제와 원래부터 잘 맞아서, 레이아웃은 거의 그대로 두고 **안에 들어가는 숫자만 실제 분석 결과로 교체**하는 방식으로 사용합니다.

## 실제 분석 결과로 교체해야 할 부분

분석 저장소의 `notebooks/03_model.ipynb`, `04_eval.ipynb` 결과가 나오면, 아래 파일들을 순서대로 손봅니다. (자세한 내용은 분석 저장소 `CLAUDE.md`의 "대시보드 재사용" 섹션 참고)

| 파일 | 지금 있는 내용 | 바꿔야 할 내용 |
|---|---|---|
| `src/data/mock.ts` | 예시로 만든 가짜 숫자 전부 | 실제 분석 결과(JSON/CSV에서 뽑은 값)로 교체 |
| `src/pages/Detail.tsx` | RUL 패널 + 생존곡선(예시) | 워크롤 잔여 마일리지 예측 결과로 교체 |
| (센서 추이 부분) | 진동/온도/압력 라벨(예시) | force/torque/tension/motor_power 라벨로 교체 |
| (모델 성능 부분) | feature importance + P/R/F1(예시) | 실제 `Anomaly_*` 라벨 기준 모델 성능으로 교체 |
| (정비 이력 부분) | `maintenanceHistory`(예시) | `work_roll_mileage` 리셋 지점 = "롤 교체 이벤트"로 변환해서 교체 |
| `src/pages/Simulation.tsx` | AS-IS/TO-BE 비용 비교(예시 숫자) | 실제 비용 시뮬레이션 결과로 교체 |
| `src/components/EquipmentDiagram.tsx` | 압축기 그림(다른 설비 그림) | 5개 스탠드(롤러 구간) 단순 박스 다이어그램으로 교체 필요 — **유일하게 그림 자체를 새로 그려야 하는 부분** |

## 실행 방법

```bash
npm install
npm run dev
```

빌드(정적 배포용):

```bash
npm run build
```

## 기술 스택

Vite + React + TypeScript, Tailwind v4, Recharts. 백엔드 없이 정적 JSON/데이터를 그대로 import해서 화면에 뿌리는 구조입니다.

## 데이터 연결 방식

분석 쪽에서 결과를 CSV/JSON으로 내보내면, 그 값을 `src/data/mock.ts`(또는 이를 대체하는 새 데이터 파일)에 그대로 붙여 넣는 방식으로 연결합니다. 별도 백엔드/API 서버는 두지 않습니다.
