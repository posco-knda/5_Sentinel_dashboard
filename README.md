# Sentinel Dashboard (시연용 대시보드)

**5조 · 팀명 "감시자들"** — 냉간압연 설비 이상탐지 & 잔존수명(RUL) 예측 프로젝트의 시연용 웹 대시보드입니다.

> ⚠️ 이 저장소는 **공식 제출물이 아닙니다.** 강사님 진행가이드 기준 공식 제출물은 별도의 분석 저장소(노트북/코드/보고서)에 있습니다. 이 대시보드는 결과보고서/발표 7장("현장 활용 근거")의 **시연 도구**로만 사용합니다.
>
> 분석 저장소는 아직 GitHub에 만들어지지 않았습니다 — 만들어지면 이 자리에 실제 링크를 넣습니다.

## 이게 뭔가요

기존에 만들어둔 예지보전(PdM) 대시보드 프로토타입을 그대로 가져온 것입니다. 화면 구성(이상탐지 현황 → 설비 상세 → 잔존수명/생존곡선 → AS-IS/TO-BE 비용 비교)이 이번 주제와 원래부터 잘 맞아서, 레이아웃은 거의 그대로 두고 **안에 들어가는 숫자만 실제 분석 결과로 교체**하는 방식으로 사용합니다.

## 지금 상태

라벨/구조는 이미 TCM 냉간압연 5단 텐덤 주제에 맞게 다 바꿔뒀습니다 (설비명 → Stand 1~5, 센서 라벨 → force/torque/tension/motor_power, RUL → 워크롤 잔존 마일리지(km) 등). **남은 건 숫자를 진짜 분석 결과로 갈아끼우는 것뿐입니다.**

분석 쪽 `03_model.ipynb`, `04_eval.ipynb` 결과가 나오면, 아래 파일의 더미 값을 실제 값으로 교체합니다:

| 파일 | 바꿀 내용 |
|---|---|
| `src/data/mock.ts` | 더미 숫자 전부 → 실제 분석 결과(JSON/CSV에서 뽑은 값) |
| `src/pages/Detail.tsx` | RUL(워크롤 잔존 마일리지) 패널 + 생존곡선의 더미 값 |
| (모델 성능 부분) | feature importance + P/R/F1 더미 값 → 실제 `Anomaly_*` 라벨 기준 모델 성능 |
| (정비 이력 부분) | `maintenanceHistory` 더미 값 → 실제 `work_roll_mileage` 리셋(롤 교체) 이력 |
| `src/pages/Simulation.tsx` | AS-IS/TO-BE 비용 비교 더미 숫자 → 실제 비용 시뮬레이션 결과 |

## 실행 방법

```bash
npm install
npm run dev
```

빌드(정적 배포용):

```bash
npm run build
```

## 기술 스택

Vite + React + TypeScript, Tailwind v4, Recharts. 백엔드 없이 정적 JSON/데이터를 그대로 import해서 화면에 뿌리는 구조입니다.

## 데이터 연결 방식

분석 쪽에서 결과를 CSV/JSON으로 내보내면, 그 값을 `src/data/mock.ts`(또는 이를 대체하는 새 데이터 파일)에 그대로 붙여 넣는 방식으로 연결합니다. 별도 백엔드/API 서버는 두지 않습니다.
