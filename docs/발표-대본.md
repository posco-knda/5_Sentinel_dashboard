### 말할 때 지킬 점
- **날짜는 말하지 않습니다.** 화면의 날짜는 촬영한 날 기준이라 매일 바뀝니다. "약 열흘", "2주 전", "5일 전"처럼 상대 표현만 씁니다.
- 총 절감액(1,830억)이나 "고장 115건 → 0건"은 화면에는 보이지만 **말로 강조하지 않습니다.** 경보 구간 엔진을 사후 검증한 시뮬레이션이라, 총액을 앞세우면 과장으로 들립니다. 한 대당 비용만 말합니다.
- `@Sentinel`은 말로는 "골뱅이 센티널"입니다.
- 폰은 1:27쯤부터 2:35까지만 나옵니다. 폰이 나오는 순간("책임자 폰에 바로 전달됩니다")과 문장을 맞추세요.

### 시간 조절
| 상황 | 방법 |
|---|---|
| 말이 빨라서 시간이 남을 때 | 정비 효과 장면(2:41~)에 `선택 ①`, 챗봇 장면에 `선택 ②`를 덧붙입니다 |
| 말이 느려서 밀릴 때 | 0:17 구간의 "오늘 할 일은 눌러서 체크합니다"와 1:46 구간의 "승인 기록은 이력에 남습니다"를 뺍니다 |

- **선택 ①** (정비 효과, 슬라이더 장면): "고장 나기 전에 미리 정비해서 줄인 비용입니다. 비용 단가는 가정값이고 설정에서 바꿀 수 있습니다."
- **선택 ②** (챗봇 장면 끝): "답변마다 근거가 붙어서, 틀린 숫자를 말하면 바로 확인할 수 있습니다."

## 3. 예상 질문과 답

| 질문 | 답 |
|---|---|
| 예측 오차는 얼마나 되나요? | 시험 엔진 248대 기준 평균 절대오차 약 17 cycle(약 6일), RMSE 약 25 cycle입니다. 그래서 날짜 하나가 아니라 90% 구간과 정비 준비 기간을 함께 씁니다. |
| 30% 절감은 믿을 만한가요? | 경보 구간 115대를 실제 남은 수명으로 사후 검증한 **시뮬레이션**입니다. 안전 여유의 최적값을 같은 데이터에서 골랐기 때문에 실제로는 이보다 작을 수 있고, 정기 정비도 가장 유리한 주기를 미리 안다고 가정해 유리하게 계산했습니다. 단가는 공개 자료 기반 가정값이고 설정에서 바꿀 수 있습니다. |
| 기본 알림 기준에서 위험 엔진을 놓치지 않나요? | 가장 비용을 아끼는 '비용 최우선'은 과거 검증 데이터에서 위험 엔진의 88%를 잡고 오경보는 0.6%입니다. '균형'은 96%·1.7%, 놓침을 최소로 하는 '안전 최우선'은 100%·2.8%입니다. 놓침과 불필요한 점검 사이의 선택이라 화면에서 근거를 같이 보여 주고 사람이 고르게 했습니다. |
| 챗봇이 틀린 숫자를 말하면요? | 챗봇은 일정·엔진 조회 같은 시스템 도구만 부를 수 있고, 답 아래 '근거 보기'에서 어떤 조회를 했는지 보여 줍니다. 일정 변경이나 승인은 할 수 없는 읽기 전용입니다. |
| 기한이 이미 지난 엔진은 어떻게 하나요? | 결재 요청에 가동 한계일 뒤 일정이 표시되고, 책임자가 승인할 때 **긴급 예외 승인**으로 바뀌어 사유를 꼭 적어야 합니다. 이력에도 [긴급 예외]로 남습니다. |
| 처음 화면에 기한 지난 엔진이 왜 이렇게 많나요? | 도입 첫날을 가정한 데이터입니다. 그동안 관리되지 않던 위험 엔진이 한꺼번에 드러난 상태입니다. |
| 지도의 비행기는 실제 운항인가요? | 아닙니다. 색의 비율과 올렸을 때 나오는 엔진 값만 실제 데이터이고, 노선과 위치는 표시용입니다. |
| AI 요약은 무엇을 쓰나요? | 서버에 연결된 AI(Gemini)가 주간 통계를 요약합니다. 연결이 없으면 기본 요약을 대신 보여 줍니다. |
| PDF는 어떻게 저장되나요? | 브라우저의 인쇄 기능으로 저장합니다. 영상에서는 인쇄 창이 녹화되지 않아 '저장했습니다' 알림으로 대신 보여 주었습니다. |
